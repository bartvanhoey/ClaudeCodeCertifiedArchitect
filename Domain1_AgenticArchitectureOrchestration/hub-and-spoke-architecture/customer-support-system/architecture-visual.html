🏗️ Hub-and-Spoke Architecture

True AI Subagent Pattern with Autonomous Reasoning

The Hub (Orchestrator)

OrchestratorAgent

Routes incoming issues intelligently

Responsibilities:

  • Dynamic routing (LLM-based)
  • Agent coordination
  • Response synthesis
  • No domain decisions

The Spokes (Subagents)

💰 BillingAgent

Handles refunds, invoices, payments

check_account_balance get_invoice process_refund

🔧 TechnicalAgent

Diagnoses service issues

check_service_status get_error_logs restart_service

👤 AccountAgent

Manages accounts & escalations

get_customer_history update_contact_info escalate_to_human

How It Works

1
Customer submits issue

Web form or API call

↓
2
Orchestrator routes intelligently

LLM analyzes issue, determines best agent

↓
3
Subagent processes autonomously

• Decides what tools are needed

• Executes tools and analyzes results

• Iterates until complete

• Makes independent decisions

↓
4
Orchestrator synthesizes response

Creates professional customer-facing response

↓
5
Customer receives resolution

Clear, empathetic, actionable response

Key Differences: Autonomy Levels

Aspect Simple Function Calls True Subagents
Type Function dispatch Autonomous agents
Tool Access None Domain-specific
Loops Single call Multi-turn iterations
Decision Making None (predetermined) Independent
Routing Fixed order Dynamic/intelligent
Autonomy Very Low High

Example: Billing Issue Resolution

Issue: "I was charged twice for my subscription"

Step 1: BillingAgent receives issue Step 2: Agent thinks: "I need to investigate" Step 3: Agent calls check_account_balance Step 4: Results show duplicate charge Step 5: Agent thinks: "Need more details" Step 6: Agent calls get_invoice Step 7: Confirmed duplicate charge of $89.99 Step 8: Agent thinks: "Customer deserves refund" Step 9: Agent calls process_refund Step 10: Refund processed successfully Step 11: Agent thinks: "I have enough information" Step 12: STOP and report findings to orchestrator Result: Refund of $89.99 processed for duplicate charge

Key insight: The agent decided to use those tools in that order. It wasn't scripted. It could have decided differently based on the results.
